# PetShop

## Problemática

Desarrollar una plataforma de comercio electrónico completa con carrito de compras, gestión de productos y pasarela de pago simulada.

## Consideraciones

- Estado global con Pinia
- Diseño con Tailwind CSS
- Backend serverless con Firebase
- Autenticación de usuarios
- Persistencia de datos

## Proceso de Desarrollo

1. **Discovery**: Análisis de funcionalidades necesarias para un e-commerce básico
2. **Diseño**: Diseño de la interfaz de usuario y experiencia de compra
3. **Desarrollo**: Implementación del catálogo, carrito y checkout
4. **Integración**: Conexión con Firebase para autenticación y base de datos
5. **Deploy**: Publicación en Vercel
