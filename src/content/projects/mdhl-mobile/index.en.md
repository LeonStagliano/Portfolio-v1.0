# Mighty Ducks Hockey League - Mobile App

## Problem

Crear una aplicación de gestión de tareas intuitiva con funcionalidades de drag & drop y persistencia local.

## Considerations

- Interfaz drag & drop para reorganizar tareas
- Persistencia en LocalStorage
- Filtrado y búsqueda de tareas
- Estados de tarea (pendiente, en progreso, completada)
- Diseño limpio y minimalista

## Proceso de Desarrollo

1. **Discovery**: Definición de funcionalidades core y user stories
2. **Diseño**: Diseño de la interfaz con enfoque en usabilidad
3. **Desarrollo**: Implementación con Composition API y drag & drop
4. **Almacenamiento**: Persistencia con LocalStorage y sincronización
5. **Deploy**: Publicación como aplicación estática
